# Portfolio Website 🌐

This is a personal portfolio website built using **HTML** and **Tailwind CSS**. It showcases my skills, projects, and contact information in a clean and responsive design.

---

## 🔧 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- GSAP
- Swiper JS
- Locomotive JS

---

## 📁 Folder Structure

. ├── images/ # Image assets ├── node_modules/ # Node dependencies (ignored in Git) ├── index.html # Main HTML file ├── output.css # Generated CSS from Tailwind (ignored in Git) ├── package.json # Project metadata and dependencies ├── package-lock.json # Dependency lock file ├── portfolio.css # Custom CSS (if any) ├── portfolio.js # JavaScript functionality ├── tailwind.config.js # Tailwind CSS configuration
